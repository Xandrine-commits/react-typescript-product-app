
# React TypeScript Product App

A React and TypeScript application built with Vite to practice reusable components, state management, API integration, and interactive product browsing.

## Features

- Fetch products from the DummyJSON API
- Display product information using reusable React components
- Search products by title
- Sort products by price and name
- Paginate product results
- View selected product details
- Handle loading and error states
- Retry failed API requests
- Reset search, sorting, selection, and pagination
- Practice controlled forms and input validation

## Technologies

- React
- TypeScript
- Vite
- HTML and CSS
- Fetch API
- DummyJSON API

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/Xandrine-commits/react-typescript-product-app.git
```

Navigate to the project folder:

```bash
cd react-typescript-product-app
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal.

## Production Build

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## API

Product data is fetched from [DummyJSON](https://dummyjson.com/products).

An internet connection is required to retrieve live API data.

## Learning Goals

This project demonstrates practical experience with React components, TypeScript interfaces, hooks, event handling, API requests, conditional rendering, search, sorting, and pagination.
